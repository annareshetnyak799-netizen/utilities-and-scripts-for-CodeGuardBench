## Что означает строка

В гайдлайне пункты разделены точкой с запятой вне inline-кода; в CAT-0.0 — запятыми. Альтернативы через `/` и перечисления внутри одного пункта сохранены вместе ровно как в источнике. Это техническая граница строки, не объединение похожих шаблонов. Поле `source_text` в JSON сохраняет исходный пункт с разметкой. Контрпримеры, классы и severity из исторического гайдлайна не экспортируются как новые шаблоны или метки.

Авторская форма — схема представления/исполнения: `$()`, `bash -c`, массив argv, alias, рекурсия, heredoc и другие. Одни и те же B01–B36 повторяются отдельными строками для каждой из семи подкатегорий. В CAT-7 формы B22/B23 используют shell aliases вместо Git aliases. Краткие схемы созданы для этого каталога; полные инструкции и проверки сохранены в источниках и JSON. Схемы с `<КОД>`, `<АРГУМЕНТЫ>` и стрелками — метасинтаксис, а не исполняемые примеры. Переводы строк в aliases и heredoc значимы.

`--` обычно завершает разбор опций у поддерживающих его утилит; он не завершает выполнение команды. Его поддержка и позиция зависят от конкретной утилиты. Эта строка добавлена по примеру пользователя, не выдана за найденный внешний шаблон.

## Происхождение и ограничения

Гайдлайн взят из [evidence/guideline.md](https://github.com/annareshetnyak799-netizen/utilities-and-scripts-for-CodeGuardBench/blob/438c9fec99ddb0285a031b7c78c3548dd2204e51/tools/d3-judge-pipeline/evidence/guideline.md#L1) на коммите `438c9fec99ddb0285a031b7c78c3548dd2204e51` указанной пользователем ветки. Файл совпадает с локальным исходником S003. Таблица передаёт содержимое поля «Шаблоны», а не утверждает актуальность исторической политики классов.

[Авторские библиотеки](https://github.com/annareshetnyak799-netizen/utilities-and-scripts-for-CodeGuardBench/tree/35dcf221b5f3fea94e06995c21e2a3ede3898d28/templates/synthetic-seed-templates/sources) впервые закреплены здесь коммитом `35dcf221b5f3fea94e06995c21e2a3ede3898d28`. Это ссылка на публикацию авторского снимка, а не свидетельство заимствования из внешнего репозитория. Пять исходных файлов сохранены побайтно; их SHA256 и относительные пути находятся в `sources/manifest.json`. CAT-2.1 хранит формы внутри axes.py; соседние сценарии в этом снимке не увеличивают число строк каталога.

404 строки не равны 8 910 seed-заданиям или 248 базовым сценариям. Матрица сценарий × форма и результаты модельных прогонов не входят в таблицу. Наличие формы в каталоге не означает совместимости с каждым сценарием: в банках есть исключённые сочетания. Авторские формы сохраняют статус draft; семантическая валидация и независимость семейств от test не подтверждены. Safety-класс по одному совпадению с шаблоном не назначается. Каталог не предназначен для допуска в train/few-shot: он включает справочные шаблоны гайдлайна и не является изолированным train-банком.

## Форматы и воспроизводимость

- [TABLE.md](TABLE.md) — одна общая таблица для просмотра на GitHub.
- [templates.json](templates.json) — те же 404 строки с полными контрактами форм и ссылками.
- [summary.json](summary.json) — точные счётчики и контрольные данные.
- `sources/` — закреплённые библиотеки и обозначения.

Из этого каталога в Git checkout:

```bash
python3 build.py --check
```

Для пересборки: `python3 build.py`. Нужны Python 3.9+ и Git с обоими указанными коммитами; внешние пакеты не нужны. Исходные Python-библиотеки читаются через AST/literal_eval, шаблоны не исполняются. Проверка сверяет снимки с Git, SHA256, все исходные пункты, 36 форм на каждую подкатегорию, число строк и побайтовую воспроизводимость.
