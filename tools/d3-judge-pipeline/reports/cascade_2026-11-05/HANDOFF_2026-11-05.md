# Handoff к встрече 5 ноября 2026

Работающее техническое демо готово. Семантическая валидация judge на независимом human gold **не состоялась**: такого gold пока нет. Более сложный каскад не показал убедительного преимущества в пилоте. Автоматический выпуск gold запрещён.

## Что реализовано

- CLI/Python API внутри существующего D3; чистая установка Python3.11.9 и CPU demo проверены. **212 тестов проходят.**
- Registry42 с SHA/линиями Guideline, прямыми комментариями Софьи, v0 overlays и proposed binary mapping. Prompt собирается из registry. Semantic/classifier/critic/optional arbiter; unknown/context/schema/provider failures уходят на review.
- Слепые входы, разделение references, process-safe бюджет и writers, resume fingerprint, quarantine неполной последней строки, human-lock export. Исправлены старые P999/handmade/taxonomy/split/comparison bugs; min-pair contract, secret shapes и ограничение размера/бюджета.
- Адаптеры D1/D2 сохраняют provenance отдельно. Privacy review D2 не заменено автоматическим маскированием. Приватные Codex-логи в API не отправлялись.

## Что реально оценено

- Два репозитория, все доступные remote refs. Canonical3425 строк =1250 train +2175 test. Из test200 старых modify/defer исключены явно; **1975** прошли полный rules/mock diagnostic. Правила дали27 предложений; mock0. Это не LLM-оценка на1975.
- **32 peer команды, 16 подкатегорий CAT-1/2/3/4**, заранее замороженные ID. Семь вариантов включая rules, single, static+single, reasoning single, critic, specialists, semantics+critic. Настоящие Qwen3-32B и gpt-oss-120b. Никакой class/risk/source/description коллег в prompt.
- CAT-0 и CAT-5–9 отсутствуют у коллег в доступных ветках: отмечены нулями. Отдельные126 authored fixtures проверяют transport; отдельный real-model probe42 содержит39 calls и30 nonabstain. Он не является human gold или дополнительным peer test.
- Старый v1 с gpt-oss-120b прошёл те же32 ID; raw agreement 34.4%. Это отдельная версия policy/schema. Qwen legacy partial сохранён после повторных таймаутов, не включён как завершённый.

## Что показать на встрече

1. Запустить команду demo из DEMO.md — без GPU/весов/ключа.
2. Открыть TEAM_COMPARISON.csv и конкретные disagreements, включая abstain и false-allow.
3. Передать внешнему агенту обновлённый ZIP в CodeBench/exports/CodeGuardBench_Cascade_Review_2026-11-05.zip. В нём нет токена, приватных логов и весов; абсолютные пользовательские пути очищены с отдельным manifest.
4. Для человека открыть human_review/blind_review.jsonl:52 карточки без подсказанных меток. Reference key открывать после первого независимого решения.
