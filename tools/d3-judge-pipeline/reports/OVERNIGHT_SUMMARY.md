# Завершённый этап: pipeline и judge, 01.11.2026

Пользователь сузила задание до пайплайна и judge. Сбор источников, расширение
CAT-2 и новый аудит команд остановлены. До уточнения уже опубликованы175команд;
этот инженерный этап не меняет data-ветки и не добавляет выбранные команды.

Работают local Hugging Face и OpenAI-compatible adapters, command-only judge,
версионированные промпты и JSON schema, статические проверки, очередь ручного
ревью, раздельная генерация test/train, проверки lineage и экспорт после human lock.
Selector делит synthetic данные по family_id; regex — признаки для ревью,
не доказательство сложности или безопасности. Данные/метки не исполняются.

## Генерация

Два test-only эксперимента:4seeds ×2кандидата каждый, всего16 proposals,
ничего не принято в test/train. V1 все8 не соответствуют запрошенным сценариям.
V2 ближе к Git, но семантика/контрпримеры остаются ненадёжными:

- CAT-2.1: обычный atomic push ошибочно назван deny; lease counterpart allow.
- CAT-2.2: hard reset/clean в submodule опасен; описание ошибочно обещает
  рекурсивность без --recursive. Safe counterpart смотрит только staged paths.
- CAT-2.3: exclude не удаляет исключённый файл; выдуман --preview=… .
- CAT-2.4: destructive expire+gc правдоподобен, но у git gc нет --dry-run.

Это агентская QA, не человеческая приёмка. Bash syntax valid не означает
валидные опции Git или верные labels. Исходные результаты сохранены неизменно.
Старый V1 копировал requested risk в risk; новые запуски оставляют risk=null
и отдельное requested_risk до разметки. Ни одна пара не считается gold.

## Воспроизводимость и ограничения

Модели, revisions, параметры, prompt/input hashes, raw outputs и ошибки сохранены.
Первичные92 judge-вызова и8 generation-вызовов сделаны на реализации65efe14.
Старые manifest не имеют implementation_sha: они архивные, не продолжать их
новым кодом. Новые прогоны включают hash кода/схем/промптов, запрещают resume
после изменений и строго проверяют схему генерации. Структурно неверный ответ
сохраняется как failed с raw, без принятия кандидатов. Grammar-constrained
HF decoding не реализован; проверяем ответ после генерации.

Пилот покрывает CAT-2, не всю таксономию. Нет независимого human gold, проверки
на untouched holdout и утверждённого порога auto-accept. Проверки lineage и
строкового сходства не доказывают отсутствие семантического leakage.
Train drafts вне репозитория остаются quarantine; новые IDs не доказывают
независимые семьи. Seed author не получал test/real examples.

Повторная сводка без модели: `python -m scripts.summarize_experiments`.
Очередь с предложениями — HUMAN_REVIEW_QUEUE.jsonl; независимая слепая форма —
HUMAN_REVIEW_BLIND.csv. После независимых разметок нужны разбор разногласий и
новый holdout; текущие диагностические проценты не использовать как gold quality.
