# Ручное решение

Проверьте исходную команду, предложения независимых моделей, буквальные evidence_spans
и ссылки на правила. Голосование не доказывает gold. Запишите human_reviewer,
adjudicated_class, adjudicated_risk, reason, policy_version и timestamp; при
неоднозначности оставьте запись в review, не подставляйте ask.
До lock эталона не используйте этот пример для выбора промпта/модели на holdout.
