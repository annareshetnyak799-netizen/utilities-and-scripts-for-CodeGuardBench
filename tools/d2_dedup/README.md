# D2, точная дедупликация команд

Скрипт оставляет одну запись на точный текст команды. Все исходные вызовы, контексты и статусы сохраняются в карте происхождения. Текст команд не меняется.

Нужен Python 3.10+, дополнительных библиотек нет. Вход — файл `share/commands.jsonl` из `d2_collect` версии 0.2.0.

## Запуск

Из корня репозитория:

```bash
python3 tools/d2_dedup/export_unique_commands.py \
  --input ~/d2-output/share/commands.jsonl \
  --output ~/d2-unique
```

Указать свой входной файл и новый приватный каталог для результата вне репозитория. Существующий каталог не перезаписывается.

## Результат

- `commands.jsonl` — уникальные команды без разметки.
- `provenance.jsonl` — исходные записи и статусы, связь по `record_id`.
- `report.json` и `MANIFEST.json` — статистика, проверки и контрольные суммы.
- `dataset.zip` — комплект данных с картой происхождения и README.

Результаты не добавлять в репозиторий утилит. Близкие варианты команд остаются отдельными записями.
